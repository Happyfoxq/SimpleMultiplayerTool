# SimpleMultiplayerTool
S&amp;box library that makes it easy to multiplayer
# How to use it?
It's easy! Just drag and drop server prefab into your scene and congifure it.

There are many options to configure so let me tell you about everything.
Player Prefab - The player prefabs server uses for players. You can set default one from the library, or set yours.
Players - The list of all players on the server.
Custom variables - you can set custom variables here! (Only int variables supported now)
Does Need Timer - Set this on true if your gamemode does need timer.
Does Players Need Health - Set this on true if your gamemode uses health system.
Does Players Need Money - Set this on true if your gamemode uses money system.
Time - The main timer of your gamemode.
Game Time - How long the game will be.
Relax Time - How long the relax after game will be.
Game Spawn Point & Relax Spawn Point - Spawn points for when your game starts, and when it ends.
Is Game Running - Bool that tells if is game running or not.
Spawn Points - Other spawn points.
Min Players Need - Do i really need to explain something here?
Debug Mode - Igrnores min players need if true
On Game Started - Action that invokes when the game starts
On Game Stopped - Action that invokes when the game stops
Custom Action - If you need other actions use this!
